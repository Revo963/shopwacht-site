02

So läuft eine Prüfung

  1. 1

    Auslösen

    Stichwortmuster entscheiden, welche Fragen zu einem Produkt gehören, und liefern die zitierte Textstelle.

  2. 2

    Beurteilen

    Die Fragen gehen an ein kleines, günstiges Entscheidungsmodell – je dreimal, gemittelt.

  3. 3

    Nachsehen

    „Fehlt“-Befunde wie der Grundpreis werden an der echten Produktseite geprüft, im Browser gerendert.

  4. 4

    Rechtstexte

    Impressum, Widerrufsbelehrung, Widerrufsbutton und Datenschutzerklärung werden für den ganzen Shop geprüft.

  5. 5

    Zweite Prüfung

    Zwei weitere Modelle lesen jedes Produkt unabhängig. Was beide verwerfen, fällt weg; „Risiko“ bleibt nur, wenn beide zustimmen.

03

In drei Schritten startklar

ShopWacht läuft auf Ihrem eigenen Rechner. Es gibt kein Konto und keinen Server von uns.

  1. 1

    Node.js installieren

    Version 22 oder neuer von nodejs.org. Chrome, Chromium oder Edge ist empfohlen: Dann werden Produktseiten so geprüft, wie ein Kunde sie sieht.

  2. 2

    Herunterladen und starten

    $ git clone https://github.com/Revo963/shopwacht.git
$ cd shopwacht
$ npm install
$ npm start
ShopWacht läuft auf http://localhost:3000

    Ohne Git: ZIP-Datei herunterladen, entpacken und im Ordner npm install und npm start ausführen.

  3. 3

    Schlüssel eintragen, Shop prüfen

    Im Browser http://localhost:3000 öffnen, den eigenen Schlüssel von openrouter.ai/keys einfügen (am besten mit Ausgabenlimit) und die Shop-Adresse eingeben. Ohne Schlüssel läuft ein grober Demo-Modus.

05

Läuft bei Ihnen. Bleibt bei Ihnen.

  • Kein Konto, kein Tracking

    Die Anwendung antwortet nur auf Ihrem Rechner und schickt nichts an uns.

  • Was den Rechner verlässt

    Anfragen an den geprüften Shop – und die gelesenen Produkt- und Rechtstexte, die über Ihren Schlüssel an OpenRouter und die Modellanbieter dahinter gehen.

  • Nur öffentliche Adressen

    Eine geprüfte Seite wird in einem Browser auf Ihrem Rechner geöffnet. ShopWacht lässt sie nur öffentliche Internetadressen erreichen, nichts in Ihrem eigenen Netz.

  • Berichte gehören Ihnen

    Jeder Bericht liegt als Datei auf Ihrer Festplatte und lässt sich als CSV exportieren.
